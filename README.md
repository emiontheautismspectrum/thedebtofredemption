# The Debt of Redemption

**35 LVL Game Jam · Механика независимости · Дарк фэнтези**

Он никогда не был автором собственной судьбы. Теперь он на дне, и Вседарущий одарил его совершенными способностями. Чтобы подняться — каждую придётся отдать.

## Запуск

### Браузер
Открыть `index.html` в Chrome или Firefox.

### Десктоп (.exe)
```bash
npm install
npm run start          # запуск в окне
npm run build:win      # сборка .exe (Windows)
npm run build:linux    # сборка (Linux)
```

## Управление
| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Пробел | удар |
| Shift | рывок |
| 1, 2, 3 | выбор при отречении |
| Телефон | левая часть — джойстик, правая — удар |

## Структура
```
index.html          — точка входа
data/
  gifts.json        — дары и воспоминания
  floors.json       — ярусы, баланс, грехи
  lines.json        — диалоги, интро, концовки
assets/
  art/              — спрайты и тайлы
  audio/            — музыка и SFX
electron/
  main.js           — обёртка для .exe
```

## Кто какие файлы трогает
| Кто | Файлы |
|---|---|
| A (техника) | `index.html`, `src/` |
| B (нарратив) | `data/gifts.json`, `data/lines.json` |
| C (визуал) | `assets/art/` |
| D (звук) | `assets/audio/` |
| E (дизайн) | `data/floors.json`, README, страница itch |
